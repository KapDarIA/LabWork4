# ЭКОНОМИКА ОТРАСЛИ 
## Оборотный капитал предприятия

*ОБС* - оборотные средства

*ОБК* - оборотный капитал

*Оборотный капитал*(ОБК) - это часть капитала, заменяющее свою вещественную форму и полностью переносящее свою стоимость на стоимость готовой продукции.

Основная задача оборотного капитала: обеспечить непрерывность и бесперебойность производства.

## Кругооборот оборотного капитала 

**фото оборот оборотных средств**

Формула кругооборота:

Деньги -> Маткриалы -> Производства -> Товар -> Деньги 
<—————-/

Оборотный капитал:

1. Оборотные производственные фонды

 - Сырье
 - Материалы 
 - Тара
 - Упаковка
 - Топливо
 - Электроэнергия
 - Малоценные и быстроизнашиваемые предметы.

Они обеспечивают неприрывность производства.

2. Фонды обращения

 - Деньги
 - Готовая продукция на складе
 - Отгруженные товары
 - Дебиторская задолженность

Обеспечивают реализацию продукции.

Оборотные и производственные фонды нормируемые, а фонды обращения не нормируемые.

Источники для приобретения оборотных средств:

- собственное 
- здания
- привлечённые
