# ЭКОНОМИКА ОТРАСЛИ 
## Оборотный капитал предприятия

*ОБС* - оборотные средства

*ОБК* - оборотный капитал

*Оборотный капитал*(ОБК) - это часть капитала, заменяющее свою вещественную форму и полностью переносящее свою стоимость на стоимость готовой продукции.

Основная задача оборотного капитала: обеспечить непрерывность и бесперебойность производства.
